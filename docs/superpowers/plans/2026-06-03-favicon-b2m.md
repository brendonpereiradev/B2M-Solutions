# Novo Favicon B2M Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Regenerar o pacote de favicons a partir de `favicon-source.png` (tamanhos pequenos) e `b2m-favicon.png` (tamanhos grandes), e atualizar cache bust para `?v=6` em 10 páginas HTML.

**Architecture:** Script Node pontual (`scripts/generate-favicons.mjs`) executado via `npx` com `sharp` e `to-ico`, sem adicionar `package.json` ao projeto. HTML mantém os mesmos 5 `<link>`; só muda a query string de versão.

**Tech Stack:** Node.js (npx), sharp, to-ico, HTML estático, verificação via `rg` e browser.

**Spec:** `docs/superpowers/specs/2026-06-03-favicon-b2m-design.md`

### Task 1: Script de geração de favicons

**Files:**

- [ ] **Step 1: Criar pasta `scripts/` se não existir**

Run:
```bash

```

- [ ] **Step 2: Criar `scripts/generate-favicons.mjs`**

```javascript
import { writeFileSync } from 'node:fs';
import { dirname, join } from 'node:path';
import { fileURLToPath } from 'node:url';
import sharp from 'sharp';
import toIco from 'to-ico';

const __dirname = dirname(fileURLToPath(import.meta.url));
const FAV_DIR = join(__dirname, '..', 'assets', 'img', 'favicons');
const SOURCE_SMALL = join(FAV_DIR, 'favicon-source.png');
const SOURCE_LARGE = join(FAV_DIR, 'b2m-favicon.png');
const BLACK = { r: 0, g: 0, b: 0, alpha: 1 };

async function resizeSquare(input, size, output) {
  await sharp(input)
    .resize(size, size, { fit: 'fill' })
    .png()
    .toFile(output);
}

async function letterboxSquare(input, size, output) {
  await sharp(input)
    .resize(size, size, { fit: 'contain', background: BLACK })
    .png()
    .toFile(output);
}

async function main() {
  const out16 = join(FAV_DIR, 'favicon-16x16.png');
  const out32 = join(FAV_DIR, 'favicon-32x32.png');
  const outIco = join(FAV_DIR, 'favicon.ico');
  const outApple = join(FAV_DIR, 'apple-touch-icon.png');
  const outAndroid = join(FAV_DIR, 'android-chrome-192x192.png');

  await resizeSquare(SOURCE_SMALL, 16, out16);
  await resizeSquare(SOURCE_SMALL, 32, out32);

  const buf16 = await sharp(out16).png().toBuffer();
  const buf32 = await sharp(out32).png().toBuffer();
  writeFileSync(outIco, await toIco([buf16, buf32]));

  await letterboxSquare(SOURCE_LARGE, 180, outApple);
  await letterboxSquare(SOURCE_LARGE, 192, outAndroid);

  const checks = [
    [out16, 16, 16],
    [out32, 32, 32],
    [outApple, 180, 180],
    [outAndroid, 192, 192],
  ];

  for (const [file, w, h] of checks) {
    const meta = await sharp(file).metadata();
    if (meta.width !== w || meta.height !== h) {
      throw new Error(`${file}: expected ${w}x${h}, got ${meta.width}x${meta.height}`);
    }
  }

  console.log('Favicons generated successfully.');
}

main().catch((err) => {
  console.error(err);
  process.exit(1);
});
```
